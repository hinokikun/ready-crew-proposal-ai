# Offline Evaluator

The offline evaluator scores blueprint readiness only. It does not guarantee final visual PowerPoint quality.

Score categories:

1. Contract Validity
2. Message Clarity
3. Intent Alignment
4. Visual Suitability
5. Content Completeness
6. Hierarchy Readiness
7. Rendering Safety
8. Customer-facing Cleanliness
9. Numeric Integrity Readiness
10. CTA Readiness

Output:

- `total_score`
- `grade`
- per-category score
- issues
- reasons
- recommendations

Required note:

```text
Blueprint構造上の準備度であり、PowerPointの最終的な視覚品質を保証しません。
```
