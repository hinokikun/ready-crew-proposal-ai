# Known Limitations

- Phase 1 does not render PowerPoint.
- Phase 1 does not call AI.
- Phase 1 does not connect to Version81 generation flows.
- Offline score is a readiness score, not a final design quality score.
- Diagram catalog coverage is represented through contract values, not renderer support.
- JSON Schema is generated from Pydantic v1 models and should be reviewed again before public API use.
- Golden JSON covers contract readiness and does not prove visual quality.
