# Slide Blueprint Boundary

## Deck Blueprint decides

- overall deck goal
- audience
- story arc
- sections
- slide order
- slide role
- expected message per slide
- relationship between previous and next slide
- decision path

## Slide Blueprint decides

- one slide purpose
- headline
- main message
- supporting evidence
- visual type
- diagram
- hierarchy
- typography
- layout
- CTA
- rendering metadata

## Boundary rule

Deck Blueprint must not carry renderer details such as font size, coordinates, color codes, and shape internals.

Slide Blueprint must not reorder the deck or change the overall story arc.
