# Known Limitations

- Phase 1.5 does not connect to existing Proposal generation.
- Phase 1.5 does not connect to Story Engine.
- Phase 1.5 does not render PPTX.
- Phase 1.5 does not add API routes.
- Deck Offline Evaluator is a readiness score, not a final design or sales success score.
- Deck fixtures are synthetic and do not include real customer information.
- Deck-level schema is generated from Pydantic v1 models and should be reviewed before public API exposure.
