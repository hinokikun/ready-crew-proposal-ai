# Story Arc Rules

Story Arc rules are recommendation and validation rules, not fixed templates.

## Supported Story Arcs

- `problem_solution`
- `current_future`
- `why_what_how`
- `insight_recommendation`
- `opportunity_solution_impact`
- `diagnosis_strategy_execution`
- `executive_decision`
- `custom`

## Example: problem_solution

Recommended order:

1. cover
2. executive_summary
3. background
4. problem
5. insight
6. solution
7. kpi
8. roadmap
9. pricing
10. next_action

## Validation principle

The validator checks relative order when both sections exist. It does not force every recommended section unless the deck declares it in `required_sections`.
