# Product Vision

## Product Definition

- プロダクト名: AI営業秘書
- 内部プロジェクト名: Ready Crew Proposal AI
- プロダクトカテゴリー:
  - AI Sales Enablement Platform
  - AI Proposal Creation Platform
  - Proposal Operating System

## Mission

営業担当者が資料作成に時間を使うのではなく、顧客理解、提案判断、顧客との対話に集中できるようにする。

## Vision

案件情報を起点として、案件分析、顧客分析、競合分析、提案戦略、提案ストーリー、提案資料、見積、PowerPoint、PDF、Beautiful.ai、営業アクション、フォローアップを一貫して支援するAI営業支援基盤を構築する。

## Core Value

| Value | 説明 | システムで保証すること |
|---|---|---|
| 早く作れる | 非構造な案件情報から初稿を短時間で作る | かんたん入力、Prompt Builder、ワンクリック生成 |
| 伝わる | 顧客が理解しやすい順番で整理する | Story Engine、Slide Objective、Quality Score |
| 説得力がある | 根拠、見積、Next Actionが揃う | Evidence管理、見積整合性、Quality Gate |
| 社内品質を統一できる | 担当者差を減らす | テンプレート、PPT品質ルール、レビュー |
| 営業ノウハウを再利用できる | 過去提案や事例を活用する | Knowledge AI、Best Practices、履歴 |
| 成果を測定できる | 時間短縮と品質を可視化する | 作成履歴、業務改善レポート、CSV |

## Target Users

| User | 主な目的 |
|---|---|
| 営業担当者 | 案件入力、提案書生成、PPTX/PDF/Beautiful.ai出力 |
| Webディレクター | ヒアリング情報整理、提案ストーリー確認 |
| 提案担当者 | Story、Slide、見積、品質チェック |
| 営業マネージャー | 提案品質、作成履歴、改善状況の確認 |
| 事業責任者 | 提案の方向性、KPI、意思決定資料確認 |
| 経営者 | 事業成果、投資対効果、営業品質の把握 |
| 管理者 | ユーザー、権限、監査、診断、運用 |

## Non Target Users

- 高度な自由デザインだけを目的とするデザイナー。
- 汎用プレゼン制作だけを目的とするユーザー。
- 動画編集、DTP、印刷組版を目的とするユーザー。
- 営業提案の判断を人間が一切確認しない完全自動送信用途。
- 個人情報や秘密情報を無制限にAIへ送信する用途。

## Product Boundary

AI営業秘書はPowerPointエディターそのものではなく、営業提案を作るための作戦、構成、資料、出力、レビューを支援するプロダクトである。PowerPointの完全互換編集より、営業担当者が顧客へ提出できる提案品質を優先する。
