# SCR-060 Story Review

## Purpose

AIが選んだ営業ストーリーを人間が確認し、PPT化前に方向性を確定する。

## Layout

```text
[Story type / reason]
[Main message]
[Slide story flow]
[Missing evidence / objections / answers]
[Approve | Revise | Back]
```

## Operations

- ストーリータイプ変更。
- 主張の編集。
- スライド役割の編集。
- 不足根拠の確認。

## Current Implementation

Version80ではUI上のStory確認はあるが、Strategy Engine出力との完全接続と保存は未完了。
