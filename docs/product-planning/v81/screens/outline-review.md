# SCR-070 Slide Outline Review

## Purpose

PPT生成前に、スライド構成、役割、結論、図解方針を確認する。

## Layout

```text
[Slide list]
  01 Cover
  02 Executive Summary
  ...
[Selected slide detail: objective / message / visual intent / evidence]
[Move up/down] [Add] [Duplicate] [Delete]
```

## Validation

- CoverとNext Actionは必須。
- 同じLayoutが3枚以上連続する場合は警告。
- Evidenceなしの断定表現は警告。

## Future Save

SlidePlanとしてProposalVersionに保存する。
