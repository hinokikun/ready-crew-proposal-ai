# PPT Design Principles

## Target

16:9の営業提案資料。日本語を主対象とし、英語混在にも対応する。

## Principles

- 1スライド1メッセージ。
- 結論先行。
- 十分な余白。
- 見出し、本文、補足、数値の階層を明確化。
- 本文17pt未満を避ける。
- 箇条書きは最大6件を目安。
- 1スライドの本文は原則400文字以下。
- 同一レイアウト3枚以上連続を避ける。
- 編集可能なPowerPoint Shapeを優先。
- 見積、Story、Next Actionとの整合性を確認。

## Forbidden

- 根拠不明な実績値。
- 文字だけの長文スライド連続。
- 画像化された編集不能テキスト。
- Web制作以外の案件にSEO/CMS等を固定混入。
- 過度な装飾と低コントラスト。
