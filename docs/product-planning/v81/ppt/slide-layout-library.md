# Slide Layout Library

| Layout | Use | Required Elements |
|---|---|---|
| Title Cover | 表紙 | title, subtitle, brand, visual |
| Section Divider | 章切り | section title, short message |
| Executive Summary | 要約 | 3 key points |
| Problem Statement | 課題 | problem map, impact |
| Current vs Future | 現状/将来 | before, after, change |
| Before / After | 比較 | two flows, human/AI role |
| Three Points | 提案骨子 | 3 cards |
| Four Cards | 機能/価値 | 4 cards |
| Process Flow | 業務流れ | nodes, arrows |
| Timeline | 計画 | phases, dates |
| Roadmap | 中長期 | milestones |
| Comparison Table | 比較 | rows max 6, cols max 4 |
| Competitor Matrix | 競合 | axes, notes |
| KPI Dashboard | 指標 | metric cards, baseline/target |
| Large Number | 重要数字 | number, context |
| Case Study | 事例 | situation, action, result |
| Quote | 顧客/現場の声 | quote, source |
| Risk and Countermeasure | リスク | risk, impact, mitigation |
| Schedule | 実施 | phase, deliverable |
| Pricing | 見積 | cost groups, assumptions |
| Team | 体制 | roles, responsibilities |
| Next Action | 次の行動 | checklist, owner |
| Closing | 結び | message, contact |
