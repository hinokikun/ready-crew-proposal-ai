# PPT Quality Rules

| Rule | Severity | Auto Repair |
|---|---|---|
| Title too long | warning | shorten suggestion |
| Body too dense | warning | split suggestion |
| Font too small | critical | increase or split |
| Element overflow | critical | resize/reflow |
| Low contrast | critical | color token change |
| Same layout repeated | warning | layout variant |
| Missing page number | warning | add |
| Missing next action | warning | ask human |
| Estimate mismatch | critical | human review |
| Unsupported external image | critical | remove/replace |
