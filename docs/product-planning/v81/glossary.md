# Glossary

| Term | Definition |
|---|---|
| Project | 案件。顧客、進行、CRM情報を持つ単位。 |
| Proposal | Projectから作られる提案単位。 |
| Proposal Brief | Prompt Builderで正規化した提案入力。 |
| Strategy Brief | Strategy Engineが作る提案戦略。 |
| Story Plan | 営業ストーリーとスライド構成。 |
| Slide Plan | 各スライドの目的、メッセージ、図解方針。 |
| Proposal Studio | Story、Slide、Design、Qualityを編集する中心画面。 |
| Presentation Designer | PPTテンプレート、レイアウト、見せ方を決める機能。 |
| Presentation AI Engine | スライドの情報設計と表示設計を行うAI/ルール層。 |
| Proposal Agent | 案件状況、ToDo、提案スコア、営業支援を扱う機能群。 |
| Proposal Copilot | 画面内で相談するチャット型支援。 |
| Proposal Intelligence | 優先順位、受注確率、KPI、営業洞察。 |
| Quality Gate | 提出前チェック。 |
| Quality Score | 提案書品質の0〜100評価。 |
| Template | PPTデザインテンプレート。 |
| Design Theme | 色、余白、フォント、部品の設計。 |
| Brand Kit | 会社ロゴ、色、フッターなどのブランド設定。 |
| Knowledge | 過去提案、事例、FAQ、社内資料。 |
| Generation Job | 長時間生成処理を管理する単位。 |
| Artifact | PPTX、PDF、Beautiful.ai URLなどの成果物。 |
| Workspace | 実務データの境界。 |
| Organization | テナントまたは会社単位の境界。 |
| Demo Data | 実データと分離された検証用データ。 |
