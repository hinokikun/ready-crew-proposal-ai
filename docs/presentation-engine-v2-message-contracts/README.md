# Presentation Engine 2.0 Message Contracts

This directory stores the external contract artifacts for Phase 2C Message Designer Foundation.

## Files

- `slide-message-design.schema.json`: schema for one slide-level message design.
- `message-designer-input.schema.json`: schema for the offline input contract.
- `message-designer-output.schema.json`: schema for the complete planner output.
- `slide-message-design.example.json`: valid single-slide example.
- `message-designer-output.example.json`: valid multi-slide output example.
- `slide-message-design-invalid-examples.json`: invalid examples used for validation discussion.

## Boundary

Message contracts contain no Slide Blueprint, layout, diagram, theme, typography, chart, image, coordinates, renderer metadata, PPTX, API, or database contract.
