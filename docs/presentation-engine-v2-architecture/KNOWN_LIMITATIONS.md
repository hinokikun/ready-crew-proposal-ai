# Known Limitations

## Current Limitations

- Presentation Engine 2.0 does not yet generate PowerPoint.
- Visual Director is not implemented.
- Blueprint Composer is not implemented.
- Renderer is not implemented.
- Version81 runtime is not connected.
- Theme, typography, layout, chart, and diagram generation are not implemented.
- OpenAI and Beautiful.ai are not connected to Presentation Engine 2.0.
- Evaluation uses synthetic fixtures and does not guarantee sales outcome.

## Quality Limitations

- Message quality depends on upstream deterministic rules.
- Some fixtures may not represent real customer complexity.
- Visual quality cannot be judged until Phase 3 to Phase 5 exist.
- Accessibility and brand compliance are future extensions.

## Operational Limitations

- No API endpoint exists for Presentation Engine 2.0.
- No DB persistence exists.
- No frontend screen exists.
- No production feature flag exists for runtime use.
