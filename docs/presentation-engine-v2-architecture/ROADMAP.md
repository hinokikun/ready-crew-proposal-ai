# Roadmap

## Phase 3: Visual Director

Convert Slide Intent into a Visual Plan.

Exit criteria:

- visual plan schema
- visual validator
- visual evaluator
- 30 fixtures
- 20 golden outputs
- no renderer connection

## Phase 4: Blueprint Composer

Convert Visual Plan into renderer-ready editable slide blueprint.

Exit criteria:

- blueprint object model
- layout-safe constraints
- overflow strategy
- accessibility metadata
- renderer contract draft

## Phase 5: Renderer

Render PowerPoint from blueprint only.

Exit criteria:

- editable PPTX
- no business logic in renderer
- visual regression tests
- broken relationship checks
- overflow checks

## Phase 6: Version81 Integration

Connect behind feature flag.

Exit criteria:

- legacy default preserved
- approved strategy adapter
- UAT workflow
- rollback path

## Production Ready

Production readiness requires:

- real-case validation
- human visual review
- performance testing
- security review
- feature flag rollout plan
- support and rollback documents
