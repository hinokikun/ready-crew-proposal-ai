# Evidence Planner Rules

## Rule Inputs

- Deck section type
- Slide role
- Slide goal
- Proposal Context
- Budget signal
- Competitive signal
- Customer proof signal

## Source Types

- Customer Interview
- Internal KPI
- Industry Statistics
- Market Research
- Competitor Analysis
- Financial Estimate
- Project Experience
- User Feedback
- Implementation Result
- Public Information
- Customer Document
- Assumption Log

## Section Rules

- Problem and Current State require customer proof.
- KPI, ROI, Pricing, and Estimate require numeric evidence.
- Competitor sections require competitor analysis.
- Solution, Approach, Roadmap, and Risk prefer project experience or implementation result.
- Next Action requires customer decision confirmation.

## Warning Rules

- Missing numeric evidence creates a blocking warning.
- Missing customer proof creates a warning.
- Missing competitor analysis creates a warning.
