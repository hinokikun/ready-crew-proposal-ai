# Presentation Engine 2.0 Deck Contracts

This directory contains machine-readable Deck Blueprint contract artifacts for Phase 1.5.

| File | Purpose |
|---|---|
| `deck-blueprint.schema.json` | JSON Schema for one Deck Blueprint |
| `deck-blueprint.example.json` | Valid example deck payload |
| `deck-blueprint-invalid-examples.json` | Invalid examples used by tests |
| `deck-slide-reference-contract.json` | Contract between Deck Blueprint and Phase 1 Slide Blueprint |

These files are offline contracts only. They are not connected to Proposal generation, Story Engine, Presentation Designer AI, PPTX rendering, API, DB, Frontend, or Beautiful.ai.
