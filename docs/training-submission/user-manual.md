# Ready Crew Proposal AI 利用マニュアル

このマニュアルは、社内研修課題でReady Crew Proposal AIを使う人向けの操作手順です。パスワード、APIキー、シークレットはこの文書には記載しません。

## 1. 公開URLへのアクセス

1. 管理者から共有された公開URLをブラウザで開きます。
2. 画面が表示されない場合は、管理者へURLと表示されたエラーを連絡します。

## 2. ログイン

1. メールアドレスとパスワードを入力します。
2. ログインできない場合は、メールアドレス、権限、有効状態を管理者へ確認してください。

## 3. 案件概要入力

1. ホーム画面またはSTEP 1で、案件メール、議事録、ヒアリングメモを貼り付けます。
2. 実在顧客の機密情報を入力する場合は、社内ルールに従ってください。

## 4. AI分析

1. 「この内容で提案書を作る」または「ワンクリック提案書」を押します。
2. AI分析の進捗が表示されます。
3. エラーが出た場合は、時間をおいて再試行し、解決しない場合は管理者へ連絡します。

## 5. 提案書生成

1. STEP 3で提案内容を確認します。
2. 会社名、金額、納期、AI推測項目を確認します。
3. 問題がなければ提出前チェックへ進みます。

## 6. PPTX出力

1. 提出前チェックを完了します。
2. PowerPoint生成ボタンを押します。
3. ダウンロードされたPPTXを開き、内容を確認します。

## 7. PDF出力

1. 提出前チェックを完了します。
2. PDF生成ボタンを押します。
3. 見積内容を確認します。

## 8. Beautiful.ai生成

1. 提出前チェックを完了します。
2. Beautiful.ai生成ボタンを押します。
3. 新しいタブでBeautiful.aiが開きます。開かない場合は、ブラウザのポップアップ許可を確認してください。

## 9. 作成履歴の確認

1. 作成履歴を開きます。
2. 案件名、生成日時、出力形式、生成時間を確認します。

## 10. 業務改善レポートの登録

1. 業務改善ダッシュボードを開きます。
2. 使用前時間、AI入力時間、AI処理待ち時間、確認時間、修正時間、品質、ミス件数、コメントを入力します。
3. 保存ボタンを押します。
4. 使用後合計時間、短縮時間、短縮率は自動計算されます。

## 11. 研修提出レポートの出力

1. 業務改善ダッシュボードで「研修提出レポートを作成」を押します。
2. 表示されたMarkdownを提出資料へ貼り付けます。
3. 実測データがない場合は「実測データ未登録」と表示されます。

## 12. CSV出力

1. 「研修提出CSV」を押します。
2. CSVには実データだけが出力されます。
3. デモデータを含める場合は、画面で「デモデータも表示」を選んでからCSV出力します。提出用には通常使いません。

## 13. よくあるエラーと対処

| エラー | 対処 |
| --- | --- |
| ログインできない | アカウントの有効状態とパスワードを管理者へ確認します。 |
| Beautiful.aiが使えない | 提出前チェック、権限、Beautiful.ai設定を確認します。 |
| PDFやPPTXが出ない | 再試行し、解決しない場合はrequest_idや画面表示を管理者へ共有します。 |
| 短縮率が表示されない | 使用前時間が0より大きいか確認します。 |
| デモデータが混ざっている | 「実データのみ表示」に切り替えてください。 |

## 14. ログアウト

1. 画面右上またはメニューからログアウトします。
2. 共用PCでは、ブラウザを閉じる前に必ずログアウトしてください。
