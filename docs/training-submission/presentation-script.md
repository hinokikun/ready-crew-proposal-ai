## 1. 改善前の課題

これまで、提案書作成では案件情報の整理、提案構成の作成、見積確認、PowerPointやPDFへの出力に時間がかかっていました。特に、案件ごとに構成を考える作業と、提出前の確認作業が属人的になりやすい点が課題でした。

## 2. 作成したReady Crew Proposal AI

今回、Ready Crew Proposal AIを使い、案件概要の入力からAI分析、提案書生成、PowerPoint、PDF、Beautiful.ai出力、業務改善レポート登録までを一つの流れで確認できるようにしました。

## 3. 主な機能

主な機能は、案件概要入力、AI分析、提案書生成、提出前チェック、PowerPoint生成、PDF生成、Beautiful.ai生成、作成履歴、業務改善ダッシュボード、研修提出レポート作成です。

## 4. 実際の使用方法

実際には、案件メールやヒアリングメモを貼り付け、AIで提案内容を整理し、提出前チェックを行ったうえで、必要な形式で出力します。作業後には、使用前時間、AI入力時間、AI処理待ち時間、確認時間、修正時間を記録しました。
