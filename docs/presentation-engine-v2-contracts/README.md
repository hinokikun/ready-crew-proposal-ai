# Presentation Engine 2.0 Contracts

This directory contains machine-readable contract artifacts for Phase 1.

| File | Purpose |
|---|---|
| `slide-blueprint.schema.json` | JSON Schema for one Slide Blueprint |
| `slide-blueprint.example.json` | Valid example payload |
| `slide-blueprint-invalid-examples.json` | Invalid examples used by tests |

These files are generated from `backend/app/presentation_engine_v2/` models and fixtures. They are offline contracts only and are not connected to API, DB, frontend, existing PPTX generation, or Beautiful.ai.
