# Version 80 Proposal Experience Edition

Version 80 は、新しい営業AI機能を増やすのではなく、初めて利用する社員が迷わず提案書作成を進められる体験へ整理するためのUI/UXアップグレードです。

## 目的

- 画面を縦に長くしすぎず、役割ごとのビューへ分ける
- 管理者向け情報と一般利用者向け提案作成を分離する
- Prompt Builderで入力を簡単にする
- Story Engineで提案ストーリーを作成前に確認する
- 3ペイン編集でスライド構成、プレビュー、AI改善提案を同時に扱う
- Presentation DesignerでPowerPointデザインテンプレートを選択する

## 維持するもの

- 既存の提案生成API
- Guided Flow
- Quality Gate
- PowerPoint / PDF
- Beautiful.ai連携
- 作成履歴
- 業務改善レポート
- 管理者診断
