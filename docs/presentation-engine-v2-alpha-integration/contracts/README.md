# Alpha Integration JSON Contracts

This directory contains generated JSON Schema and examples for the offline Alpha Integration Review.

## Files

- `integration-case-input.schema.json`
- `integration-case-output.schema.json`
- `integration-evaluation.schema.json`
- `cross-module-validation.schema.json`
- `phase2d-readiness.schema.json`
- `example.json`
- `invalid-examples.json`

All schemas are generated from the Python contract models and use JSON Schema Draft 2020-12.
