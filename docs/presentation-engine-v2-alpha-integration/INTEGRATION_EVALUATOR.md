# Integration Evaluator

The Alpha Evaluator scores the pipeline on 16 dimensions.

1. Contract Integrity
2. Proposal Context Coverage
3. Story Coherence
4. Deck Structure Quality
5. Audience Fit
6. Decision Flow
7. Evidence Completeness
8. Evidence Traceability
9. Numeric Integrity
10. Message Clarity
11. Evidence and Message Alignment
12. Slide-to-slide Consistency
13. Sales Readiness
14. Executive Readiness
15. Customer-facing Cleanliness
16. Phase 2D Readiness

Blocking issues cap readiness even when the numeric score is high.
