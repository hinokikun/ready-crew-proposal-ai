# Blocker Report

Current fixture-generated outputs do not show P0 blockers in the default 20-case review set.

## Blocker Definition

P0 blockers include:

- Contract-breaking version mismatch
- Broken slide references
- Missing required evidence without disclosure
- Unsupported numeric or ROI claim
- Runtime/PPTX/API/DB boundary crossing
- Placeholder or internal label in customer-facing message

## Handling

If a P0 blocker appears, Phase 2D should not start until the responsible module is corrected.
