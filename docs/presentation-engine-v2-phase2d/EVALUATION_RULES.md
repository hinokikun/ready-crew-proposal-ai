# Evaluation Rules

Slide Intent is scored on a 100-point scale using nine dimensions:

1. Intent Clarity
2. Visual Readiness
3. Information Hierarchy
4. Reading Flow
5. Evidence Compatibility
6. Message Compatibility
7. Diagram Suitability
8. Chart Suitability
9. Customer-facing Readiness

Grades:

- S: 95+
- A: 90+
- B: 80+
- C: 70+
- D: 60+
- F: below 60

This score evaluates Phase 2D readiness only. It does not evaluate final PowerPoint design quality or sales outcome.
