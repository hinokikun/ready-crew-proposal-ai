# Message Generation Rules

## Limits

- Headline: 60 characters
- Main message: 120 characters
- Supporting messages: maximum 3
- Supporting message: 80 characters
- Key takeaway: 80 characters
- Speaker note summary: 300 characters

## Generation Boundary

The generator may create message fields only. It must not create:

- Headline-derived body copy
- Slide Blueprint
- Diagram
- Layout
- Theme
- Typography
- PowerPoint

## Evidence Behavior

If required evidence is missing, the generator:

- lowers message confidence,
- avoids definitive claims,
- adds missing evidence disclosure,
- adds warnings,
- keeps unsupported claims out of the visible message.
