# Phase 2C Message Designer Foundation

Phase 2C adds an offline Message Designer that converts Proposal Context, Deck Blueprint, and Evidence Planner output into slide-level message contracts.

## Goal

The goal is to decide what each planned slide should say before Slide Blueprint generation starts.

## In Scope

- Headline
- Main message
- Supporting messages
- Key takeaway
- Speaker note summary
- Message style and tone
- Evidence alignment summary
- Missing evidence disclosure
- Message warnings
- Validation result
- Offline evaluation result

## Out of Scope

- Slide Blueprint generation
- Body copy generation
- Diagram generation
- Layout, theme, typography, color, image, chart, shape, coordinate, or PPTX generation
- Existing proposal generation connection
- Backend API
- Frontend
- DB or migration
- Beautiful.ai

## Status

Phase 2C is an offline foundation only.
