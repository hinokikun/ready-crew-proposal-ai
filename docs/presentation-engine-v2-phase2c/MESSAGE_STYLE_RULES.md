# Message Style Rules

## Styles

- executive
- consulting
- sales
- marketing
- technical
- operational
- financial
- strategic
- neutral

## Selection Rules

- Executive audience selects `executive` unless a stronger financial rule applies.
- KPI, insight, and competitor sections select `consulting`.
- Pricing, estimate, and ROI sections select `financial`.
- Roadmap, timeline, and approach sections select `operational`.
- Solution and scope sections may select `technical`.
- Recommendation and closing roles may select `sales`.
- Otherwise the default is `neutral`.

## Tone

Tone is derived from the selected style profile. Financial tone is cautious, consulting tone is analytical, sales tone is persuasive, and executive tone is concise.
