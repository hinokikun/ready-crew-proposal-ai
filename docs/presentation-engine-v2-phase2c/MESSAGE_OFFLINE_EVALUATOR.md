# Message Offline Evaluator

## Score

The evaluator produces a 100-point score and grade.

## Dimensions

- Contract Validity
- Headline Quality
- Message Clarity
- One-slide-one-message
- Evidence Alignment
- Numeric Integrity Readiness
- Narrative Consistency
- Audience Fit
- Decision Relevance
- Customer-facing Readability
- Executive Readiness
- Sales Persuasiveness

## Note

The evaluator scores message readiness only. It does not score final PPTX design quality, visual design, or sales outcome.
