# Known Limitations

- The Message Designer is deterministic and rule-based.
- It does not use external LLM reasoning.
- It does not guarantee final visual quality.
- It does not generate body copy.
- It does not judge whether a customer will buy.
- It does not verify evidence content against real source documents.
- It depends on Deck Planner and Evidence Planner output quality.
- Some Japanese wording is intentionally conservative to avoid unsupported claims.
