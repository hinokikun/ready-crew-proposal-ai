# Planner Golden

## Golden Count

20 planner results are stored as golden outputs.

## Golden Scope

Each golden item includes:

- Proposal Context
- Deck Blueprint
- Rule decisions
- Slide recommendations
- Planner evaluation

## Stability

Golden outputs use deterministic deck IDs and a fixed Phase 2A timestamp to make offline regression testing stable.

## Usage

Golden results are not connected to runtime proposal generation. They are contract snapshots for later Phase 2B work.
