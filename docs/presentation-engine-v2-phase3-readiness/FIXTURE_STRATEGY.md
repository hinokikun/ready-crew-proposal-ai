# Fixture Strategy

## Fixture Types

| Type | Purpose | Suggested Count |
|---|---|---:|
| Normal fixtures | Representative successful Visual Plan inputs. | 30+ |
| Semi-normal fixtures | Missing but recoverable evidence or ambiguous intent. | 15+ |
| Invalid fixtures | Contract, schema, or boundary violations. | 15+ |
| Golden fixtures | Deterministic expected Visual Plan outputs. | 20+ |
| Deck-level fixtures | Cross-slide consistency and diversity. | 10+ |
| Slide-level fixtures | Single-slide rule and validator focus. | 30+ |

## Business Case Coverage

Include at least:

- corporate site
- recruiting site
- EC
- SaaS
- AI workflow automation
- sales DX
- internal system
- data analysis
- marketing
- branding
- executive short deck
- practitioner detailed deck
- competitive comparison
- ROI
- timeline
- process
- before / after
- case study
- pricing
- next action

## Visual Pattern Coverage

Fixtures must avoid overfitting to one pattern. Cover:

- hero
- summary cards
- comparison
- KPI cards
- timeline
- roadmap
- process
- hierarchy
- checklist
- matrix
- table
- number dominant
- image dominant
- text dominant
- callout

## Golden Strategy

Golden outputs should freeze:

- selected visual strategy
- layout strategy
- emphasis strategy
- component candidates
- evidence linkage
- risk flags
- confidence

Do not golden-freeze coordinates, colors, fonts, or PowerPoint objects.
