# Known Limitations

## Alpha Limitations

- No Visual Director Engine implementation.
- No Blueprint Composer.
- No Renderer.
- No PowerPoint generation through Presentation Engine 2.0.
- No production runtime integration.
- No Version81 connection.
- No API route.
- No frontend screen.
- No database persistence.
- No OpenAI or external AI call.
- No Beautiful.ai connection.

## Quality Limitations

- Fixture evaluation does not guarantee real sales outcome.
- Golden outputs prove deterministic contract behavior, not final design quality.
- Visual Plan Contract is ready but not yet exercised by a real Visual Director.
- Phase4 Blueprint Composer handoff still has partial metadata gaps.
- Audience-specific and decision-stage-specific visual behavior is not fully modeled.
- Cross-slide visual rhythm and diversity are not yet enforced by an engine.

## Operational Limitations

- Alpha modules are offline and developer-facing.
- Release package is documentation-only.
- Tests were not run during this release preparation task.
- Existing working tree contains unrelated dirty changes from prior work; this
  package does not clean, reset, or stage them.

## Migration Limitation

Version81 integration must wait until Phase3 and Phase4 produce validated
contracts and golden outputs.
