# Phase 2D Slide Intent Foundation

This package is an offline bridge between Phase 2C Message Designer and later visual design phases.

It decides what each slide should make visible:

- slide intent
- slide type
- information priority
- reading order
- visual pattern candidate
- diagram candidate
- chart candidate
- layout constraints
- rendering hint
- intent confidence
- validation and evaluation result

It does not generate Slide Blueprints, diagrams, charts, layouts, coordinates, colors, typography, PPTX, API responses, DB rows, or runtime UI behavior.
